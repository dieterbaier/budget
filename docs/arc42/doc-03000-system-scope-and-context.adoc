= System Scope And Context

Budget is a self-contained, single-user system: a React PWA, a Spring Boot
backend, and a PostgreSQL database. The only external input is the owner reading
figures from bank statements and typing them in; there is no automated bank
integration. Balances are entered by hand (see ADR-008).
