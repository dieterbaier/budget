[[con-004-plain-java]]
== CON-004: Plain Java

What is read is what is compiled, and what a class needs arrives through its
constructor.

[cols="2,3", options="header"]
|===
| Rule | Enforces
| No class uses Lombok | xref:adr-011-no-lombok[ADR-011]
| No class uses field injection | xref:adr-012-explicit-bean-configuration[ADR-012]
|===

Lombok is not on the dependency list, so the first rule checks something that
cannot happen by accident today. It is a tripwire rather than a guard: it fails
when someone adds the dependency and the first `@Data`, instead of later, once
the annotations have spread far enough to make removing them a project.

The field-injection rule is ArchUnit's own, covering `@Autowired`, `@Inject` and
`@Resource` on fields. It applies to the whole backend, not only the core — the
adapters are constructor-injected today and this keeps them that way.
