= Deployment View

== MVP — Local, Single Device

Backend and PostgreSQL run locally (a single compose setup); the PWA is served
from the same host and talks to `localhost`. This covers the single-device MVP
with no hosting or ops burden. It does not make the app reachable from a phone.

== Later — Single Always-On Host

To use the PWA on the phone, backend and PostgreSQL move to one always-on host (a
small VPS), reachable over HTTPS. Every client — desktop browser and phone — is a
thin consumer of that one backend. A shared database alone would not enable the
phone, because the phone has no backend to run; the reachable component must be
the backend, not the database (see ADR-007).

== Backups

Durability is the owner's responsibility now that Notion is gone: a nightly
`pg_dump` copied off the application host, plus an in-app export endpoint (see
Q-OPS-001). The concrete host provider is still open (Q-OPS-003).
