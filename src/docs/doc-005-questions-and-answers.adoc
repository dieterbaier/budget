This is the central discussion document for the private Budget project. It
records open and answered questions and the assumptions behind the AI-generated
bootstrap. Open questions are picked up by the generator into the open-questions
index for the architecture decisions chapter.

== Bootstrap Notes

All architecture content in this repository is an AI-generated draft produced by
the architecture-knowledge-toolkit bootstrap. Every artifact is `draft` or
`proposed` with `reviewed: false`. Draft prose was seeded from the toolkit's
private-budget example (same domain) and must be reviewed and corrected against
the real product intent before any artifact is marked `reviewed` or `accepted`.

Assumptions made during bootstrap (to confirm or correct):

* Product idea. The original bootstrap prompt left the project idea blank; it was
  confirmed interactively as a *private, single-household budgeting application*
  with offline-first mobile expense capture and server-owned budget calculation.
  See Q-PO-002.
* Clients. A mobile app for capture plus a backend; a web UI is assumed optional
  for later. See Q-PO-003.
* Technology stack. No concrete languages, frameworks, datastore, or hosting
  target have been decided. The techstack canvas and deployment chapter hold
  placeholders only. See Q-ARCH-001 and Q-OPS-002.
* Decisions. Three ADRs are proposed (backend API boundary, mobile local-first
  entry, server-owned budget calculation). They reflect the assumed idea and are
  not yet accepted. See Q-ARCH-002.
