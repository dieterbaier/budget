== R-001: Private Budget Data Exposure

=== Risk Statement

Because the self-hosted data contains personal spending patterns, weak
authentication, transport security, or logging may expose sensitive information —
especially once the backend is reachable over the internet for mobile use.

=== Assessment

[cols="1,3", options="header"]
|===
| Field | Value
| Likelihood | Medium (rises when hosted).
| Impact | High.
| Priority | High.
| Timeframe | Before the hosted deployment.
| Confidence | Medium.
|===

=== Mitigation Options

Single-user authentication with Argon2 hashing, TLS-only transport, server-side
authorization, log redaction, and off-host encrypted backups. See
xref:adr-007-single-user-deployment-and-auth[ADR-007].
