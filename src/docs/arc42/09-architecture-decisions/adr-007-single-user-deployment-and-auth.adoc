== ADR-007: Single-User Deployment Topology And Authentication

=== Status

Accepted (topology and auth direction). Host provider selection is tracked as
Q-OPS-003. Confirmed by the owner on 2026-07-24.

=== Decision

For the MVP, the backend and PostgreSQL run locally on a single device; the PWA
talks to `localhost`. To use the PWA on the phone, the backend and database move
to a single always-on host (a small VPS) reachable over HTTPS, with every client
a thin consumer of that one backend. Access is protected by single-user
authentication: one credential, password hashed with Argon2, sessions over TLS
only.

=== Decision Drivers

* One user; no need for an identity provider or multi-tenant auth.
* A PWA on the phone cannot reach a backend that only exists on the laptop's
  `localhost`; the backend — not the database — must be the shared, reachable
  component.
* Personal spending data must stay private (see xref:r-001-private-data-exposure[R-001]).

=== Considered Options

==== Local MVP, later single always-on host (chosen)

Minimal now; a clean, well-understood path to multi-device without a rewrite.

==== Shared database, app run per device

The owner's initial idea. A shared database does not enable the phone, because
the phone still has no backend to run; also risks concurrent-write and
exposure problems. Rejected.

==== Fully hosted from day one

Reachable everywhere immediately, but adds ops before it is needed for a
single-device MVP.

=== Pugh Matrix

|===
| Criterion | Local then host | Shared DB per device | Hosted day one
| MVP simplicity | +1 | 0 | -1
| Enables mobile PWA | +1 | -1 | +1
| Data-safety when remote | +1 | -1 | +1
s| Sum s| 3 s| -2 s| 1

=== Consequences

==== Positive

* The MVP has no hosting or ops burden; multi-device is a deployment change.

==== Negative

* Live views require the backend to be running (local, then hosted).

==== Neutral or Follow-Up

* Choose the concrete host (Q-OPS-003) before enabling mobile use.
* Backups: nightly `pg_dump` plus an in-app export endpoint (see Q-OPS-001).
